# 심심 공작소

**글을 쓰면 영상이 됩니다.** 대본 문법으로 적은 글을 붙여 넣으면 그대로 mp4 가 나옵니다.
그림이 없어도 배경·캐릭터·소품을 코드가 그려 주므로 대본만으로 바로 만들 수 있습니다.

- 숏츠(30초)부터 이어 붙인 20~30분짜리까지
- 굽는 데 GPU 를 쓰지 않습니다 — 30초 영상이 5~10초면 구워집니다
- 목소리(TTS)는 쓰지 않습니다. 말은 **자막과 말풍선**으로 합니다

---

## 이 저장소에 들어 있는 것

**프로그램만** 들어 있습니다 (약 45MB). 전체 폴더는 45GB 가 넘지만
생성 엔진·모델·개인 작업물은 올리지 않습니다 — `.gitignore` 참고.

```
app/
  server.py        aiohttp 서버 (8189 포트)
  api/             서버 기능들 (굽기·자산·프로젝트·이미지 생성…)
  js/
    story/         대본 파서 · 무대 · 굽기 (여기가 핵심)
    char/          캐릭터 그리기 · 얼굴 찾기 · 리깅
    ui/            어디서든 부르는 공용 부품 (팝업·줄편집기·뒤로가기)
    tabs/          화면 하나하나
    workshop/      작업실 안의 단계들
  views/           화면 (html 조각)
  fonts/  fx/      자막 글꼴 · 효과음(CC0)
  _check.html      자동 점검 142가지 — 고친 뒤 꼭 돌려 보세요
```

## 처음 준비 (같이 고치는 분께)

이 저장소만으로는 **안 돌아갑니다.** 아래 두 가지를 각자 따로 두어야 합니다.

1. **ComfyUI (생성 엔진)** — [ComfyUI 윈도우 포터블](https://github.com/comfyanonymous/ComfyUI/releases)
   을 받아 저장소 옆에 `ComfyUI_windows_portable/` 로 풉니다.
   파이썬도 이 안의 것(`python_embeded\python.exe`)을 씁니다.
2. **cloudflared.exe** (밖에서 접속할 때만) — [여기](https://github.com/cloudflare/cloudflared/releases)서
   받아 저장소 맨 위에 둡니다.

그림·음악·프로젝트는 각자 만들면 됩니다 (`app/characters`, `app/projects` … 는 안 올라갑니다).

## 켜기

| 배치 파일 | 언제 쓰나 |
|---|---|
| `AI 동영상 스튜디오 시작.bat` | 내 PC 에서만 |
| `AI 동영상 스튜디오 시작 (외부접속).bat` | 같은 와이파이의 폰·태블릿에서도 |
| `AI 동영상 스튜디오 시작 (인터넷 공개).bat` | 어디서든 (Cloudflare 터널 + 비밀번호) |

인터넷 공개 모드는 처음 켤 때 `비밀번호.txt` 를 **무작위로** 만듭니다.
이 파일은 깃에 안 올라갑니다 — 저장소에 비밀번호를 적으면 그게 곧 공개 비밀번호가 됩니다.

## 고친 뒤에 할 일

```
http://127.0.0.1:8189/p/_check.html?key=(비밀번호)
```

자동 점검 **142가지**가 돕니다. 대본 문법·무대 그리기·굽기 전 점검·뒤로가기·보기(여백·대비)까지
한 번에 봅니다. **통과 142 · 실패 0** 이 나와야 합니다.

## 대본 문법

작업실 화면의 **📄 이 시리즈로 대본 쓰기 → 📥 MD 내려받기** 를 누르면
지금 쓸 수 있는 자산까지 담은 설명서가 나옵니다. 그 글을 밖의 LLM 에 통째로 주면
바로 쓸 수 있는 대본을 써 옵니다.

문법의 진짜 정의는 [app/js/story/script.js](app/js/story/script.js) 이고,
쓸 수 있는 낱말은 [app/js/story/lint.js](app/js/story/lint.js) 의 `낱말표` 한 곳에 모여 있습니다.
설명서(`guide.js`)가 그 표를 그대로 읽으므로 **낱말을 더하면 설명서도 저절로 따라옵니다.**

## 코드를 만질 때

- 주석과 이름은 **한국어**로 씁니다. 왜 그렇게 했는지(겪은 문제)를 적어 둡니다.
- 팝업·공용 화면은 `js/ui/` 에 **따로 파일로** 만들어 어디서든 부릅니다.
- 낱말을 하나 더하면 `_check.html` 이 저절로 그것까지 검사하도록 되어 있습니다.
